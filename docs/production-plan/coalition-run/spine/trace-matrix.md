## Findings (a step no component covers is a finding, not a footnote)

- **F1: Measure/care-gap evaluation engine is unowned.** Steps 5 and 15 require HEDIS GSD/EED-class evaluation. G6 (shared metric engine) is parked; DP-2 role separation forbids the SDE from computing measures; no direction pack assigns it. Spine disposition: assign gap derivation as a named projector inside the G2 specialist's scope (it emits `care-gap.*` events per C10, consuming record events, policy-as-data like disposition policy), with an explicit note that full measure certification is out of scope. ESCALATE to owner if G2 scope growth is unacceptable; the alternative is unparking a slice of G6.
- **F2: Barrier-remediation arrangement transaction (step 11).** Proposing, referring, tracking are covered (SDE, agents, closed-loop path). Executing a booking against an external broker is covered only where a closed-loop platform (Unite Us-class) performs it; a direct-booking capability is T0 with no owner. Recorded as a scope boundary, not silently absorbed.
- **F3: Program reporting (QARR-class, step 16; outcome roll-ups, step 15).** No gap area produces regulatory reports. Adjacent capability exists (O-5 compliance-readiness report in G7 proves the generated-from-view-models pattern). Spine disposition: record as parked alongside G6 with the O-5 pattern named as the eventual template.
- **Reverse check (component no step exercises):** every active gap area (G1..G5, G7) and every X workstream is exercised by at least one row; no orphan components. GB-1..GB-7 remain blocked rows in D1, not traced here.
