# AI Governance & Algorithmic-Accountability Review (R1 domain-fidelity)

Status: FINDINGS ONLY, no source modified. Adversarial red-team of the agent coalition
(`src/lib/agentRuntime`, `src/lib/agents`), the signal-disposition engine (`src/lib/sde`),
the prior-auth / Golden-Thread coverage path (`src/lib/pa`, `src/lib/goldenThread`,
`src/lib/policy`, `src/lib/workflow/paMachine.ts`), and the care-plan generator
(`src/lib/carePlan`). Lens: would this survive a CMS-0057-F + state algorithmic-denial +
model-risk (SR 11-7 / NIST AI RMF class) review for a payer platform that CLAIMS health equity.

## Framing: the "AI" is deterministic today, but the SEAMS are ungoverned

The agents and the policy/propensity/care-plan engines are DETERMINISTIC rule code, not LLM
calls (no `openai`/`anthropic`/model inference anywhere in `src/lib`). That is a strength: no
generative denial today. BUT autonomy, manifests, policy packs, and propensity are all
DATA-DRIVEN behind `dataMode`/store-backed loaders, and an ML model is explicitly invited to
"swap in behind the same interface" (`propensity.ts`). The governance gaps below are about the
CONTROLS on those seams: nothing binds an adverse coverage action to mandatory human decision,
nothing gates a model/policy/autonomy change on evaluation, nothing tests for disparate impact,
and no member-facing reason/appeal artifact is ever produced. A regulator reviews the seam the
model drops into, not just today's rules.

## Cross-cutting note for the regulator-facing file

The single highest-leverage fix is an **enforced invariant, independent of autonomy tier, that
any action classified as coverage-affecting / adverse cannot resolve except by an explicit
qualified-human decision** — implemented at the `proposeAndWait`/`decide` seam (not per-agent
data), with the reviewer identity, inputs, fired rule + version, and a member-facing reason +
appeal artifact emitted on every such decision. That one control closes or materially reduces
AIG-01, -02, -05, -06, -07, -10, and -11 at once and is the load-bearing claim a CMS-0057-F /
state algorithmic-denial review will test first.
