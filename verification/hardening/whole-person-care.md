# Whole-Person Care — Functionality Adversary (R1 domain-fidelity, care management / care coordination)

Read-only deployment-robustness review of the CORE value prop: resolve one member,
understand the barriers that drive avoidable utilization, and orchestrate clinical +
behavioral + social + caregiver action. Question asked of every capability: does it
actually WORK end to end against real member data, or is it demo-deep?

Method: tree-of-thought, one branch per care-orchestration capability (not a linear
file walk). Findings are grounded in the built code paths, cross-checked against the
standing register (verification/GAP_AND_STUB_RISK_REGISTER.md). Severity is impact on
CARE OUTCOMES / TCOC in a real care-management operation, not build hygiene.

## Headline

The platform has TWO parallel universes that never meet. One is a genuinely
well-engineered, fail-closed, event-sourced substrate: the projected knowledge graph
+ five consent-filtered lenses (both backends), the signal-disposition engine (SDE),
the agent runtime (HITL / escalation-as-data / autonomy-as-data), EMPI survivorship,
and terminology. The other is the PRODUCT surface the value prop is demonstrated on:
a hardcoded single-patient holistic context, an 804-line hand-authored whole-person
graph for one member, authored intervention scripts, seeded signal batches, and mock
referral/gap stores. The impressive care analytics (whole-person context, root-cause /
keystone, tiered interventions, next-best-action, risk) run ENTIRELY on the authored
side and NEVER read the real substrate. The substrate is real but unwired to the UI;
the demo is wired but not real. Whole-person care, as a working end-to-end capability
against an arbitrary member, does not yet exist — it is authored for Maria Redhawk.

## Disposition summary

- Total: 16 findings — 3 CRITICAL, 8 HIGH, 5 MED.
- The three CRITICALs (WPC-01 hardcoded context, WPC-04 keystone disconnected from data, WPC-08 no gap-computation engine) are one theme: the analytics that ARE the value prop have no path to a real member's data.
- The recurring shape is not fail-open dishonesty (the substrate fails closed and is well-labeled) but UNWIRED REALNESS: excellent subsystems that no end-to-end product flow connects to each other, to the 20 domains, or to the UI. The demo is green because it runs on authored artifacts in parallel to the real code.
- What genuinely works (keep): the SDE fold, the agent runtime's HITL/escalation/autonomy/idempotency semantics, the graph projector + consent-filtered lenses, the SDOH causal-edge provenance model, the referral lifecycle model. These are production-shaped; they are just not plugged in.
- Owning iterations: most are a single "I12 wiring" integration iteration (aggregate real context over the graph, surface the projected graph, converge the plan/referral models) plus a pilot track for the two truly-absent engines (HEDIS/Stars measure computation; risk/impactability + NBA).
